# Иконки соцсетей

Сейчас тут лежат простые заглушки-кружочки, чтобы сайт не показывал
битые картинки. Замени их своими файлами с ТОЧНО такими же именами —
сайт сразу подхватит новые иконки, ничего в коде менять не нужно:

- `inst.png`   — Instagram
- `viber.png`  — Viber
- `tg.png`     — Telegram

Рекомендуемый размер: квадратный PNG, например 128×128 или 256×256,
с прозрачным фоном (если иконка не круглая сама по себе).

## Фоновая картинка на главной

- `bg-nails.jpg` — декоративное фото (например, типсы с маникюром),
  которое показывается размытым и притемнённым пятном в углу экрана
  на главной странице сайта (см. .page-bg-decor в assets/css/style.css).
  Пока файла нет — фон просто пустой, ничего не ломается. Как только
  положишь сюда файл с этим именем, он подхватится сам, без правки кода.
  Подойдёт любое достаточно крупное фото (от ~1000px по меньшей стороне) —
  оно всё равно будет сильно размыто, так что мелкие детали не важны.
