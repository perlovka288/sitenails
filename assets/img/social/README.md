# Иконки соцсетей

Сейчас тут лежат простые заглушки-кружочки, чтобы сайт не показывал
битые картинки. Замени их своими файлами с ТОЧНО такими же именами —
сайт сразу подхватит новые иконки, ничего в коде менять не нужно:

- `inst.png`   — Instagram
- `viber.png`  — Viber
- `tg.png`     — Telegram

Рекомендуемый размер: квадратный PNG, например 128×128 или 256×256,
с прозрачным фоном (если иконка не круглая сама по себе).
